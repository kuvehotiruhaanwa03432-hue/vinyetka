# ТЗ: «Виньетка», передача проекта

Состояние на 30.09.2026. Самостоятельный проект, ни с чем другим у владельца не связан (в том числе с ЛЕОН).

## 1. Что это
Сервис для специалистов автоподбора (BMW / Mercedes). Мастер регистрируется и выпускает клиенту интерактивный
отчёт по осмотренной машине. У каждого мастера свой уникальный стиль отчёта, который детерминированно выводится из его ФИО.

У владельца уже есть сайты-базы знаний по BMW и Mercedes (статьи о моделях, двигателях, типовых проблемах)
и RAG-агент. Их нужно использовать как источник ИИ-обзоров и как канал привлечения мастеров и клиентов.

## 3. Дизайн-система (не менять без согласования)
- Метафора: ценная бумага на машину. Мятная бумага (светлая тема) и ночной петроль (тёмная), гильош, перфорация, номер лесенкой, печать-розетка мастера.
- Сетка VIN-17: 17 колонок, ширины блоков из чисел Фибоначчи. Сбоку VIN-рельс, на мобиле он становится липкой полосой.
- Шрифты Google Fonts с кириллицей: Commissioner (оси FLAR/VOLM), Onest, Martian Mono, Handjet (табло ошибок).
- Цвета мастера касаются только рамки: обложки, заголовков, розетки, раскатов. Данные (вердикты, микроны, ошибки) всегда в системных цветах. Смысл дублируется формой и штрихом, не только цветом.
- Вердикты пробега: Подтверждён / Не скручен / Есть сомнения / Скручен. Кузов: шаг толщиномера 170 мкм, «шов» вокруг панели растёт с толщиной покрытия.
- Нет логотипов и фирменного стиля BMW / Mercedes. В подвале: «Независимый сервис, не связан с автопроизводителями».

## 4. Задачи

### 4.1. Деплой лендинга на Beget (сейчас)
1. Владелец добавляет секреты репозитория: `BEGET_FTP_HOST`, `BEGET_FTP_USER`, `BEGET_FTP_PASSWORD`, `BEGET_FTP_DIR` (например `/домен/public_html/`).
2. Смержить PR #1. Workflow `Deploy to Beget` зальёт `dist/`. Проверить сайт по домену: лендинг → отчёт → карта идей, телефон и десктоп.
3. Если FTP не сработает (другой хост, FTPS), поправить шаг в `.github/workflows/deploy-beget.yml`.
   Облачное окружение Claude не пускает к beget.com и не выпускает FTP/SSH наружу, поэтому заливка возможна только через GitHub Actions или вручную (архив `dist/`).
4. По решению владельца: закрыть демо от индексации (`robots.txt` / `noindex`) или, наоборот, настроить SEO и счётчик.

### 4.2. Точечные правки прототипа
- «Заменён по отзыву» у радиатора EGR смягчить до «сервисная кампания»: основные кампании касались машин до 2017 года, а демо-машина 11.2018.
- Решить с владельцем цвет Б Подборкина. Движок уводит малину в пурпурный (#9B418B) в тексте, чтобы её не путали с цветом тревоги. Если личный цвет важнее, ослабить отталкивание от danger (например, до 12°) в `vignette.js` и прогнать тесты.
- Однословные имена («Ян») дают два одинаковых цвета: доработать добивку hex.
- Проверить в Safari (iOS). Сейчас всё проверено только в Chromium.

### 4.3. MVP продукта (первые 3 месяца)
Нужен бэкенд. Стек на выбор исполнителя, но с учётом хостинга Beget (PHP/MySQL на тарифе или Node на VPS).
- Регистрация мастера, профиль, генерация стиля движком `vignette.js` (стиль фиксируется при регистрации; повернуть палитру на 137,5° можно не более 2 раз).
- Конструктор отчёта с мобильной формой осмотра:
  - пробег (свидетели: приборка, блоки, ключ, ТО, объявления);
  - кузов (13 панелей, микроны);
  - ходовая;
  - двигатель;
  - электрика (коды ошибок);
  - заявления продавца;
  - «что не проверялось».
- Публичная ссылка на отчёт для клиента плюс ссылка «для продавца» без бюджета клиента и торга.
- Режимы чтения: для клиента, для профи, «для своих».
- Смета по Москве и Санкт-Петербургу: справочник работ и запчастей (оригинал / аналог), итоги считаются автоматически.
- ИИ-обзор модели и мотора через RAG владельца, со ссылками на статьи базы, с пометкой «составлено ИИ, проверено мастером».
- Суфлёр торга: якорь, цель, точка ухода.
- Оплата: отказные отчёты бесплатно, финальный 1 490 ₽, «Про» 3 900 ₽/мес, «Бюро» 9 900 ₽/мес. Это гипотезы, в коде держать настраиваемыми.
- Согласие клиента и 152-ФЗ, хранение персональных данных в РФ.

### 4.4. Дальше (6–12 месяцев), по карте идей
Штурман осмотра по VIN и объявлению, импорт кодов ошибок (ISTA / Xentry / Launch) → рубли, Bluetooth-толщиномер и голосовой ввод, «кладбище VIN», продажа отчёта продавцу, медкарта машины после покупки, субподряд «руки в другом городе», страховка вердикта, финансирование. Подробности и приоритеты: `site/ideas.html` и `brief/brief.json` → `curated_ideas`.

## 5. Как работать с репозиторием
```bash
node engine/engine.test.js                    # тесты движка
python3 ideas-src/build_ideas.py              # пересобрать карту идей из брифа
./scripts/build-dist.sh                       # собрать dist/ для хостинга
NODE_PATH=$(npm root -g) node tools/shot.js site/report.html shots/report   # скриншоты 390/1280, светлая/тёмная
```
`site/index.html` без `<!doctype>` намеренно: так его ожидает публикатор Artifact. Для хостинга скелет добавляет `build-dist.sh`.

## 6. Критерии приёмки для любой правки
- Нет горизонтального скролла на 390 px, обе темы читаются (контраст текста ≥ 4,5:1), ошибок в консоли 0.
- Тесты движка зелёные. Суммы в сметах равны сумме строк.
- Демо-данные помечены как пример. Пароли и ключи только в секретах GitHub, никогда в коде или в чате.
